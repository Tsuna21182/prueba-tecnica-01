# React + TypeScript + Vite

App para solicitar usuarios y verlos en cards

## como correr proyecto

1. clonar el repositorio
2. npm i para (instalacion de node_module)
3. npm run dev ( para visualizacion del proyecto en ejecucion)

## Que usamos?

utilizamos React para el frontend zustand para el manejo de estados axios para las peticiones tambien usamos sweetalert2 para los mensajes de errores y react spinners para los loading para el css se uso tailwindcss
